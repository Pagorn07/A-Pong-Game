# A Pong Game

Pong clásico hecho en Godot 4, como proyecto de práctica de arquitectura y patrones 
(state machine, signals, event bus, resources, dependency injection) antes de aplicarlos 
al proyecto grande.

Ver `pong_documento_contexto.md` para el diseño completo (alcance, mecánicas, arquitectura).
